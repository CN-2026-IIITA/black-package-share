How to Set Up LAN File Sharing

1
Connect to the same Wi-Fi / Network

Both sender and receiver must be on the same local network (same Wi-Fi router or Ethernet switch).

2
Run Black Packet on both devices

Run npm start on both machines connected to the same Wi-Fi. The second device opens a browser to http://<THIS-PC-IP>:3000 — the LAN IP is shown above under "This Device".

3
Devices appear automatically

Within 5 seconds, both devices will discover each other via UDP broadcast. Click a peer to open their upload page.

4
Upload & share the access code

Upload a file on one device, then enter the 6-digit code on the other device to download — no internet needed!

How to Share Files Over the Internet

Want to send files to someone in another city? Here's how:

1
Deploy Black Packet to the cloud

Deploy this app on Render, Railway, or any cloud host. You'll get a public URL like https://black-packet.onrender.com.

2
Open the URL on your device

Visit the deployed URL in your browser and upload your file. You'll receive a 6-digit access code, QR code, or a secret share card.

3
Share the code with the receiver

Send the 6-digit code via WhatsApp, text, or email — or send the secret share card image for extra security!

4
Receiver downloads from the same URL

The receiver opens the same deployed URL, goes to Download tab, enters the code → file downloads instantly. Works across cities, countries!

Note: LAN discovery (UDP broadcast) only works on local networks. Over the internet, use the access code, QR, or share card to transfer files.
